Pertanyaan umum

Apakah data saya dikirim ke internet?

Tidak. Pemrosesan berjalan di komputermu. Internet hanya dipakai saat memasang pustaka lewat install.bat.

Apa maksud “beta”?

Aplikasi masih diuji. Pakai dokumen contoh dulu, dan periksa sendiri hasil sensor (Ctrl+F di PDF hasil) sebelum dibagikan.

Bisa untuk PDF hasil scan?

Belum. Aplikasi membaca teks yang ada di dalam PDF, dan belum punya OCR.

Syaratnya apa?

Windows dengan Python 3.10 atau lebih baru (64-bit). Jika ada error, kirim file error_log.txt agar bisa diperbaiki.
